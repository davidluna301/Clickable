# 🖱️ Clickeable
 
> Aprende a reconocer estafas digitales jugando, antes de hacer clic.
 
**Clickeable** es un proyecto de mockup web clickeable que enseña a identificar publicidad engañosa, enlaces maliciosos y ataques de phishing mediante minijuegos con una interfaz accesible y sencilla.
 
---
 
## 📌 Problema que resuelve
 
Con el incremento de estafas digitales, muchas personas sufren pérdidas de datos y dinero al interactuar involuntariamente con anuncios engañosos o correos falsos, debido a la falta de herramientas de aprendizaje intuitivas.
 
## 💡 Solución interactiva
 
Clickeable ofrece una experiencia gamificada con interfaz accesible, pasos simples y guías interactivas para reconocer elementos seguros en la web y tomar decisiones informadas antes de hacer clic.
 
---
 
## 🎮 Minijuegos
 
### Minijuego 1: Encuentra las señales peligrosas
- Se muestra una interfaz simulada (por ejemplo, un correo falso) con **7 elementos marcables**, de los cuales **3 son peligrosos**.
- La persona usuaria debe identificarlos haciendo clic sobre ellos.
- Al finalizar, se muestra la información para reconocer cada elemento peligroso y el **porcentaje de éxito**.
### Minijuego 2: ¿Cuál es el seguro?
- Se presentan **pares de ejemplos**: una posible amenaza y su equivalente seguro (correos bancarios, anuncios, enlaces).
- La persona usuaria elige cuál es el seguro.
- Después de elegir, la página entrega **retroalimentación** explicando la respuesta.
### Sección Aprende
Tarjetas con consejos rápidos: revisar el remitente, pasar el cursor sobre los enlaces y desconfiar de la urgencia.

## 🧭 Alcance del mockup
 
Esta primera etapa se centra **solo en lo visual**:
 
- ✅ Maquetación en HTML y diseño en CSS
- ✅ Navbar para navegar entre las secciones y los minijuegos
- ✅ Estados de retroalimentación maquetados como bloques estáticos
- ⏳ Lógica de los juegos (JavaScript): pendiente para una siguiente etapa
## 🎨 Lineamientos de diseño
 
- Paleta: azul profundo como color principal, verde para lo **seguro** y rojo/naranja para el **peligro**.
- Tipografía legible, botones grandes y alto contraste (accesibilidad).
- Diseño responsive para móvil y escritorio.
## 🚀 Cómo visualizarlo
 
1. Clona el repositorio:
```bash
   git clone <URL-del-repositorio>
```
2. Abre la carpeta del proyecto.
3. Abre `index.html` en tu navegador. No requiere instalación ni servidor.
